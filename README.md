## Запуск

Требуется JDK 17+ (для №14 ещё Maven 3.9+). Проверить все работы разом:

```bash
./run-all-checks.sh
```

Одна работа (на примере №7):

```bash
cd pr07
javac -encoding UTF-8 -d out src/*.java
java -cp out SelfCheck
java -cp out OrderApp
```

## Индивидуальный вариант

Номер варианта = (две последние цифры зачётки mod 8) + 1 = (58 mod 8) + 1 = **3**. Во всех работах реализован вариант 3:

| Работа | Изменяемый аспект | Реализованное правило | Где |
|---|---|---|---|
| №3-4 | порог бесплатной обработки | обработка 500 ₽ бесплатна при сумме после скидки ≥ 20 000 ₽ | `OrderCalculator.FREE_PROCESSING_THRESHOLD` |
| №5 | недельная норма | недельная переработка = max(0, сумма − 20) | `TimesheetAnalyzer.WEEKLY_NORM` |
| №6 | поведение срочной заявки | FAST_TRACK только при сумме ≤ 20 % финансового порога (100 000 ₽) | `ApprovalRouter.FAST_TRACK_PERCENT_OF_LIMIT` |
| №7 | правило объединения повторного товара | повторный товар объединяется, только если итог ≤ 20 шт. | `Order.MERGE_LIMIT` |
| №8 | дополнительная проверка даты | командировка не длиннее 20 календарных дней | `BusinessTrip.MAX_TRIP_DAYS` |
| №9 | правило списания | не более 20 единиц за одну выдачу | `Warehouse.MAX_ISSUE_PER_OPERATION` |
| №10 | ограничение по весу | новый способ «постамат» — вес до 20 кг | `ParcelLockerPolicy.MAX_WEIGHT_KG` |
| №11 | политика дубликатов | повтор ИНН отклоняется; при доле дубликатов > 20 % — предупреждение о повторном импорте | `ImportResult.DUPLICATE_WARNING_PERCENT` |
| №12 | дополнительный агрегат | доля выручки от 20 % крупнейших сделок | `SalesAnalyticsService.TOP_DEALS_PERCENT` |
| №13 | буфер между бронированиями | 20 минут между бронированиями одной комнаты | `BookingService.DEFAULT_BUFFER` |
| №14 | ограничение максимальной премии | премия не больше 20 % оклада | `BonusCalculator.MAX_BONUS_PERCENT` |
| №15 | политика резервного канала | при отказе основного канала — INTERNAL, не более 20 резервных отправок | `FallbackPolicy.DEFAULT_LIMIT` |
| №16 | дополнительный агрегат | число документов, в которых не менее 20 слов | `BatchResult.LARGE_DOCUMENT_WORDS` |

В задании параметр сформулирован как «значение или модификатор 20, точное применение определяется текстом текущего правила». Трактовка для каждой работы описана в разделе «Индивидуальный вариант» её README.
