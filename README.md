# Практические работы по Java

Решения практических работ №1–16. Каждая работа лежит в своей папке и содержит:

* `README.md` — отчёт: итоговые Activity-диаграмма и диаграмма классов (Mermaid, GitHub рендерит их сам), анализ фрагмента кода, таблица граничных проверок, собственные формулировки;
* `DECISIONS.md` — два принципиальных проектных решения;
* `src/` — исходный код, `data/sample.csv` — открытый набор данных, `SelfCheck` — самопроверка.

## Запуск

Требуется JDK 17+ (для №14 ещё Maven 3.9+). Проверить все работы разом:

```bash
./run-all-checks.sh
```

Одна работа (на примере №7):

```bash
cd pr07
javac -encoding UTF-8 -d out src/*.java
java -cp out SelfCheck
java -cp out OrderApp
```

## Индивидуальный вариант

Номер варианта = (две последние цифры зачётки mod 8) + 1. **Везде реализован вариант 1.** Параметр варианта вынесен в одну константу, и её название указано в разделе «Индивидуальный вариант» README каждой работы. Чтобы перейти на другой вариант, поменяй эту константу, ожидаемые значения в `SelfCheck` и абзац в README.
