# DECISIONS — работа №5

1. **`split(";", -1)` и проверка ровно пяти элементов до разбора чисел.**
   Обычный `split(";")` отбрасывает пустые элементы в конце, и строка `8;8;8;8;` выглядела бы как «4 значения». С `-1` пустой элемент остаётся. Пользователь получает точное сообщение «позиция 5: значение отсутствует», как требует правило о сообщении с позицией.

2. **Ошибка одного значения — исключение `IllegalArgumentException` с номером позиции, весь табель отклоняется.**
   Правило: «ошибка одного значения делает весь табель некорректным». Поэтому частичный массив не возвращается, а разбор прерывается на первой ошибке. Позиция считается с 1, как её видит человек.
